Computer Use und MCP vergleichen

Beide Seiten starten mit leerem Rechner, leerem Editor und eigenem Test-Desktop. Die Oberfläche und die Programmfunktionen sind identisch. Computer Use bedient die Oberfläche; MCP führt die Cartridge-Funktion aus.

Bedienung über Elemente und Tastatur; Bilder bei Bedarf.

Noch nicht durchgeführt.

MCP

Bedienung über Programmfunktionen und einen wiederverwendbaren Ablauf.

Noch nicht durchgeführt.

    MCP-Fähigkeiten und Grenzen

    WebMCP wird geprüft.
    

    Info identifiziert Version 1.1.0. Use enthält getrennte Themen für Rechner, Editor, Dateien und Abläufe.
Programming installiert neue Abläufe ohne Neustart. Administration enthält noch keine Einstellungen.
Ein Ablauf kann vorhandene Funktionen kombinieren, aber keinen beliebigen Code ausführen.
    

    Hier werden noch keine Token-Einsparungen behauptet. Ein Demonstrationslauf ersetzt keine Messreihe mit frischen Modellsitzungen.
